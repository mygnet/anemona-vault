# Anémona Vault

Your developer workspace inside Visual Studio Code.

Anémona Vault helps developers organize everything they use every day in one place:

- Secure secrets and credentials
- Markdown notes
- Tasks and to-do lists
- Frequently used commands
- Code snippets
- Project references

All accessible from a dedicated sidebar without leaving Visual Studio Code.

## Features

- Multiple vaults
- Markdown notes
- Secret management
- Task tracking
- Command library
- Snippet storage
- Filtering
- Local-first storage
- Workspace organization
